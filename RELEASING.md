# Releasing uDA Pulse SDK

**Status:** nothing has been published yet. The first version is `0.1.0` (the root `VERSION` file).

- Package: https://packagist.org/packages/dmorenof/uda-sdk (to be created when the first release is confirmed)
- Default branch: `master` (to be protected, with the required checks `test` and `validate`)
- PHP: `>=8.4`
- License: MIT for the SDK's own code, with third-party notices in `NOTICE.md`
- Source API contract: `contract/` (see `NOTICE.md` for where it comes from and what it leaves open)
- Automated tests do not call the live service.

## Before the first release

- `dmorenof/sdk-runtime` **1.13.0** must be published first: the SDK requires `^1.13.0` (nested form and query parameters). The CI of this repository cannot install it until then.
- The code in `src/` is generated by `sdk-generator` 1.15.0 (also unpublished). Regenerating is the only way to change `src/`; do not edit it by hand.
- Check the contract against the service (this SDK has not been run against the live API) and record what was checked in `CHANGELOG.md`.

## Publishing

A release is requested only when the owner confirms it, and only when its work is finished and proven; versions are not published piecemeal.
The workflow `.github/workflows/release.yml` publishes **only after** a pull request that changes `VERSION` merges to `master`: it validates the manifest, installs dependencies, runs the syntax check and PHPUnit, audits dependencies, creates the immutable tag `vX.Y.Z` on that commit and publishes the GitHub Release. An existing tag is never moved.
